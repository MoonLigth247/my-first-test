## Юу хийсэн бэ

Энэ репозиторид [SauceDemo](https://www.saucedemo.com) демо дэлгүүрийн нэвтрэх хуудасны
функционалыг Playwright (TypeScript)-ээр автоматжуулсан 3 тест бичив:

1. **Амжилттай нэвтрэх** — зөв нэр/нууц үгээр нэвтэрч, "Products" хуудас руу шилжсэнийг
   шалгаад, эцэст нь logout хийж тестийг зөв төгсгөв.
2. **Амжилтгүй нэвтрэх** — буруу нууц үгээр нэвтрэхэд харагдах алдааны мессежийг шалгав.
3. **Нэвтэрсний дараах үйлдэл** — нэвтэрсний дараа "Sauce Labs Backpack" бараа сагслаж,
   сагсны тоолуур болон сагсны хуудсанд бараа орсныг шалгав.

Бүх тест `getByPlaceholder`, `getByRole`, `getByText` зэрэг Playwright-ийн орчин үеийн
(user-facing) locator-уудыг ашигласан бөгөөд XPath огт ашиглаагүй.

## Playwright ба Selenium харьцуулсан ажиглалт

Playwright бол Selenium-той адил нээлттэй эхийн (Apache 2.0), үнэгүй хэрэгсэл боловч
илүү орчин үеийн архитектуртай. Хамгийн том ялгаа нь **auto-wait** механизм: Selenium дээр
явцгаадаг олон `WebDriverWait`, `sleep()`-ийг Playwright автоматаар, элемент бодитоор
харагдаж, дарагдахад бэлэн болтол хүлээснээр орлодог тул тест бичихэд хугацаа хэмнэгддэг,
код цэвэрхэн болдог. Мөн Playwright нэг suite-даараа chromium, firefox, webkit
гурвыг тусад нь driver суулгалгүй ажиллуулдаг нь орчны тохиргоог хялбарчилдаг.
Хамгийн ашигтай нэмэлт нь **trace viewer** — тест унасан үед алхам бүрийн дэлгэцийн
зураг, DOM snapshot, сүлжээний хүсэлтийг цаг хугацаагаар нь эргэн харах боломж, энэ нь
Selenium-ийн лог/screenshot-той харьцуулахад алдаа мөшгихийг мэдэгдэхүйц хурдасгадаг.
Codegen функц нь хэрэглэгчийн хийсэн үйлдлийг шууд код болгож бичдэг тул шинэ суралцагчид
эхлэхэд хялбар байсан. Selenium илүү удаан хугацаанд хөгжсөн, индустрид өргөн дэмжлэгтэй,
олон хэлний (Java, Python, C#, JS) экосистемтэй хэвээр байгаа ч, шинэ төслүүдэд дээрх
давуу талуудаас шалтгаалан Playwright сонгогдох нь нэмэгдэж байгааг лабораторийн
явцад мэдэрлээ.

## Тест isolation

Playwright-ийн `test()` функц бүр шинэ, цэвэр browser context үүсгэдэг тул тестүүд
хоорондоо cookie, session хуваалцахгүй, дангаараа бие даан ажиллана. Үүнийг баталгаажуулах
зорилгоор тест бүрийг `page.goto('/')`-оос эхлүүлж, шаардлагатай тохиолдолд logout-оор
төгсгөсөн.
